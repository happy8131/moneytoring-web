# 키움 REST API - 뉴스 기능 부재 확인

## 핵심 사실

키움 REST API(openapi.kiwoom.com)는 **뉴스 조회 TR 코드를 공식적으로 제공하지 않는다.**

2026-05-14 기준으로 공식 API 가이드의 전체 카테고리를 확인한 결과:

| 카테고리 | TR 코드 범위 | 설명 |
|---------|------------|------|
| 계좌 | ka00001, ka01690~ | 잔고, 체결 내역 |
| 종목정보 | ka10001, ka10095~ka10102 | 현재가, 기본정보 |
| 차트 | ka10079~ka50092 | 일봉, 분봉, 주봉 등 |
| 업종/지수 | ka20001~ka20009 | 업종 현재가 |
| ELW | ka30001~ka30012 | ELW 관련 |
| ETF | ka40001~ka40010 | ETF 관련 |
| 테마 | ka90001~ka90002 | 테마 조회 |
| 조건검색 | ka10171~ka10174 | 조건 검색 |
| 주문 | kt10000~kt10003 | 매수/매도 |

**뉴스 관련 TR 코드 없음.**

## 구 OpenAPI+(HTS 기반)와의 차이

구형 키움 OpenAPI+(OCX/COM 방식)는 TR `opt10000`류 외에도 뉴스 조회 기능이 일부 포함되어 있었으나,
신형 REST API는 순수 거래/시세 중심으로 설계되어 뉴스 기능이 제외되었다.

## 대안 전략

뉴스 데이터가 필요한 경우:

1. **Finnhub** (`/news` 엔드포인트): 이미 프로젝트에 통합됨. 글로벌 + 한국 종목 뉴스 지원
2. **네이버 금융 비공식 스크래핑**: 한국 주식 종목 뉴스 (서비스 이용약관 확인 필요)
3. **Korea Investment REST API**: KIS Developers에서 뉴스 관련 API 일부 제공
4. **키움 REST API 자체**: 향후 뉴스 TR 추가 가능성 있음 → openapi.kiwoom.com 공지사항 모니터링 권장

**Why:** 키움 REST API 전체 jobTpCode 02/05/07/15 페이지를 직접 크롤링하여 확인한 결과 뉴스 TR 코드가 없음이 확인됨.
**How to apply:** 뉴스 구현 시 키움 API 사용을 시도하지 말고 Finnhub 또는 별도 뉴스 소스를 사용할 것.
